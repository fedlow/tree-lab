# Лабораторная работа: Деревья

## Цель
Научиться реализовывать бинарное дерево поиска, обходы BFS/DFS и AVL-дерево.

## Файлы проекта
- `binary_tree.py` — класс `BinaryTree` (insert/search).
- `traversals.py` — BFS, preorder, inorder, postorder.
- `avl_tree.py` — класс `AVLTree` (наследник `BinaryTree`).
- `demo.py` — демонстрация.

## 1. BinaryTree

Обычное бинарное дерево поиска (BST):
- меньше — налево, больше — направо;
- `insert(value)` — добавляет узел;
- `search(value)` — ищет значение, возвращает True/False.

## 2. BFS

Обход в ширину — по уровням. Использует `collections.deque`.
Для дерева выше BFS даёт: `[50, 30, 70, 20, 40, 60, 80]`.

## 3. DFS

Три обхода:
- **preorder** (корень → левое → правое): `[50, 30, 20, 40, 70, 60, 80]`
- **inorder** (левое → корень → правое): `[20, 30, 40, 50, 60, 70, 80]` — отсортированный
- **postorder** (левое → правое → корень): `[20, 40, 30, 60, 80, 70, 50]`

Для BST `inorder` всегда даёт элементы по возрастанию.

## 4. AVLTree

Наследует `BinaryTree`. После каждой вставки проверяет balance factor:
- если левое поддерево выше правого на 2 — правый поворот (LL или LR);
- если правое выше на 2 — левый поворот (RR или RL).

Методы:
- `left_rotate`, `right_rotate` — повороты;
- `rebalance` — решает, какой поворот применить;
- `_insert` — BST-вставка + балансировка.

Благодаря балансировке высота AVL — O(log n), а не O(n), как у вырожденного BST.

## Вывод

BST быстр, но может выродиться в список (если вставлять по возрастанию).
AVL-дерево автоматически балансируется поворотами, гарантируя O(log n)
на вставку и поиск. BFS обходит по уровням, DFS — вглубь, тремя разными
порядками. Inorder для BST — отсортированный список.
